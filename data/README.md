# Recovered data

Selected `objects.xml`/`grounds.xml` and map assets remain third-party material; the backend license does not relicense them. `sfx/music/sorc.mp3` is the selected client's requested track, recovered unchanged from moistosaurus/realm-src `1855c017eab870d13f0b61b1cf0b9e66a01922ff`, `common/resources/web/music/sorc.mp3` (see `REALM-SRC-LICENSE`); The non-music MP3 clips in `sfx/` are unchanged files from that pin's `common/resources/web/sfx/`. No separate audio-rights grant is claimed.

**Map candidates, not authenticated official 123.5.1 layouts:**
- Tutorial, Kitchen, Nexus, Limbo and Vault: trapped/rotmg_svr at `593e490803fe0ad168ead408cacd5287d778acfe`. The old 96×96 shore crop remains a reference. Live Realms select a prepared layout from `realm-catalog.json` per creation. World1, World2 and World3 are 2100×2100; the remaining layouts are 2048×2048. See `FSOD-NOTICE` and `realms/NOTICE`. The procedural island is now only a unit-test fixture.
- Guild Halls 1-4: used cells from moistosaurus/realm-src `1855c017eab870d13f0b61b1cf0b9e66a01922ff`, `common/resources/worlds/GuildHall0..3.wmap`; losslessly converted to the existing format on 16 October 2026 (all source heights are zero). See `REALM-SRC-LICENSE`.
- Oryx Castle: used-cell geometry and roster from Bledixon/Project-B-Public `9947199c8d384cc8220657bfa7519dc92e47adb9`, `server-source/wServer/realm/worlds/OryxCastle.jm` (AGPL; see root `LICENSE`). Required Project-B credits: Bledixon, Kithio, Travoos, Lunarshade, Club559, Skilly, BLOODQWEEN, Miniguy, Arcanuo, Jade, ossimc82 and everyone who helped make the project. The newer alloy Castle was rejected because it contains unsupported Janus/custom markers.
- Oryx Chamber and Wine Cellar: used-cell geometry and rosters from Zolmex/alloy-server at `c4bd1169a1593fd775b59d25a40edfa1cbd475c4`, `OryxChamber.jm` / `WineCellar.jm`; see `ALLOY-LICENSE`. JSON absent grounds retain the author's void default `0xff`; ambiguous Castle `Grey Circle` is explicitly selected as `0x61`. These are candidate layouts, not authenticated official maps.
- Pirate Cave: seeded rooms, dry corridors, water margins and connected cave walls. This is a reconstruction using selected identities and the 2015 Creepylava generator as comparator (`realm-src` pin above, `DungeonGen/Templates/PirateCave`), not a recovered official generator. The retained `pirate-cave.wmap` is the Alloy candidate fixture (`c4bd1169a1593fd775b59d25a40edfa1cbd475c4`); see `ALLOY-LICENSE`.
- Undead Lair: the same Alloy commit's `UndeadLair3.jm`; used geometry, objects and configurations retained. Its ambiguous `Grey Circle` name explicitly uses selected type `0x61`, not `0x65`.
- Sprite World: seeded rooms, conveyor colors, tiled or solid floors, and zero to five Native Sprite Gods. The May 2012 Wild Shadow guide describes those variations; this is not a recovered official generator.
- Snake Pit: seeded circular rooms, five intervening rooms, branches, filled diggable tunnels, grates, striped entrance flooring and four boss-cover walls. The geometry follows period screenshots/descriptions, not a recovered official generator; treasure layouts/frequencies remain unverified. Stheno's repeating 8/17/6-second cycle follows the pinned modified 7.0 server, not Trapped's HP gates; exact 123.5.1 timers remain unverified. Selected stats/projectiles stay authoritative.

Mad Lab uses original generated geometry and existing selected assets, not a copied/authenticated map. The GPL-3.0 `realm-src` pin above, `BehaviorDb.Lab.cs` (sebastianfra12/ossimc82), supplies the encounter/loot comparator; its first turret phase versus later potion phases is retained. The invalid boss-experiment projectile 1 is explicitly corrected to selected 0. Global irreversible <20% rage and actor-only pool geometry/source-aware remedy are disclosed reconstruction policies, not certified 123.5.1 rules. Flying Brain→Lab follows the retained 123.5.0 announcement and pinned `BehaviorDb.Mountain.cs`; 17% is the later comparator rate, not a certified period rate. Slime God does not drop Lab. Blue clears pool effects and Hexed, not unrelated combat Stunned/Speedy; blue wins overlap. Holy cleansing retains its existing effect list, and green reapplies next tick. Ordinary water is unrelated. Each hide entry fills at most one live child per kind/cage (12 total); inward collision-checked releases and selected clone XP0.1 are explicit safety/engine adaptations, not literal accumulating reference waves.

HP/projectiles use selected XML. AI/loot derive from trapped's Shore/Cave/Lowland/Midland/Highland/Mountain/SnakePit/Undead_Lair behavior tables and moistosaurus/realm-src's SpriteWorld/UndeadLair candidates at `1855c017eab870d13f0b61b1cf0b9e66a01922ff` (GPL-3.0, `REALM-SRC-LICENSE`). Native checks are partial: prepared-character Stheno/Oryx victories and a normally rolled Incantation pickup are verified, but a complete earned multiplayer journey through the implemented Realm finale is not. Realm portal rolls are explicit provisional candidate rules: Medusa→Snake17%, Sprite God's bounded Sprite Children→Glowing25%, Ghost God→Lair17% (Cubes→Cave retain1%). Solo Sprite World dexterity is guaranteed, matching the May 2012 guide; white drops stay rare. Boss shields/summons,20-second Limon corner boxes, delayed grenades, single-use traps and slime splits are bounded server actors; they are not authenticated official AI. Limon's candidate self-looping shield state is reconstructed as1.5-second vulnerable/3.5-second shielded windows. Earned base fame is XP/1000, a reference-server policy rather than verified 123.5.1 scoring; historical death bonuses are not restored. Account-private loot and Vault access are enforced server-side.
